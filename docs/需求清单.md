# 弈境 · 需求清单与实现状态

本文件原是仓库根目录的 `1.txt`（一份空文件，后来写入需求条目），2026-09-17 整理时移入
`docs/` 并补上当前实现状态，方便对照「设计目标」与「实际做到哪一步」。

## 原始需求

| # | 模块 | 需求 |
| --- | --- | --- |
| 1 | 棋谱管理 | SGF 导入（单文件/批量）、导出、删除、重命名、文件夹分类、标签管理 |
| 2 | 棋谱浏览 | 棋盘显示、落子顺序播放、前进/后退、跳至指定手数、自动播放 |
| 3 | 编辑与标记 | 添加分支变化、标记（圆圈、三角、文字）、评论、删除/插入着法 |
| 4 | AI 复盘 | 调用本地 KataGo 分析整局或部分，输出每手胜率、目差、推荐着法及变化图 |
| 5 | 可视化分析 | 胜率曲线图、目差曲线、关键手标记（如胜率骤降手）、热力图显示好坏手 |
| 6 | 搜索与筛选 | 按棋手、赛事、日期、标签、文件名搜索；支持 SGF 内容全文检索 |
| 7 | 棋谱库统计 | 对局总数、胜率统计、常用布局分析等基础报表 |
| 8 | 数据安全 | 本地 SQLite 存储，支持备份与恢复 |

热力图、统计报表）明确**不在本轮范围**，留待后续。古谱规则适配（明清规则、还棋头）不在
